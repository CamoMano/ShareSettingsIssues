# ShareSettingsIssues

Issue tracker for [ShareSettings](https://sharesettings.fyi) — the community
platform for sharing game settings, performance profiles, and controller
layouts across handhelds, desktops, and laptops.

## Report an issue

Open a [new issue](https://github.com/CamoMano/ShareSettingsIssues/issues/new/choose)
and pick a template:

| Template | Use it for |
|---|---|
| **Bug report** | Something on the site is broken or behaves unexpectedly (pages, forms, hardware autofill, sign-in, comments, ratings) |
| **Feature request** | New functionality or improvements to existing features |
| **Catalog request** | A game or hardware profile missing from the catalog |

Please fill in the forms as completely as you can — reproducible steps for
bugs, and the game/hardware name (plus specs, for hardware) for catalog
requests. Issues missing key details may be closed until the information
is provided.

## Not an issue for this tracker

- **Content or policy violations** (inappropriate reports, spam,
  impersonation): use the Flag button on the report in the app. Moderators
  handle flags in the moderation queue — public issues are not the right
  channel for user reports.
- **Account problems** (sign-in failures, data deletion): check the
  account links in your profile dropdown on the site first; open a bug
  report only if the account tools themselves misbehave.
